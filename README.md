# GalfDesign — KP3

Веб-приложение для ручного измерения площади по плану, расчёта стоимости проектирования инженерных систем и подготовки коммерческого предложения в PDF. Поддерживает загрузку изображений и PDF, ручной ввод площади и суммирование нескольких проектов.

Версия для GitHub Pages работает без ИИ. Анализ и улучшение изображений через Gemini отключены; ключ API для запуска не требуется.

## Локальный запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Сборка и просмотр готового сайта:

```sh
npm run build
npm run preview
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает проект и публикует каталог `dist` при отправке изменений в ветку `main`. Его также можно запустить вручную во вкладке Actions. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**.

Адрес после успешной публикации: [galfdesign.github.io/KP3](https://galfdesign.github.io/KP3/).

Файлы окружения, `node_modules`, готовые сборки и локальные выгрузки документов не входят в исходный код репозитория. Сайт использует внешние CDN для Tailwind CSS, PDF.js и шрифта Inter, поэтому для их загрузки нужно подключение к интернету.
